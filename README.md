# 稀疏位集合与集合运算（从 0 实现）

起始环境只有本说明、`samples/**` 与 `.gitignore`：集合解析、游程运算、`.bsf` 编解码、命令行与一页自包含
HTML 报告都从零写，Python 3.13 标准库，不引第三方、不加构建、不联网。

## 一、范围

做：读文本集合与 `.bsf` 文件；交、并、差、包含判断、基数统计、单元素判断；规范游程的编解码；把
`samples/expected/**` 逐条核对并出自包含 HTML 报告。

不做：负数与浮点数、BOM 与多字节编码；位图或通用压缩；数据库、网络、并发与多进程；增量写盘与版本迁移；
`.bsf` 之外的持久化格式；图表与图形界面；不改动 `samples/**`，除 `var/` 与报告文件外不写别的文件。

## 二、口径与公式

- 元素是整数 `x`，`0 ≤ x ≤ U−1`，`U = 2^32 = 4294967296`；全集是 `[0, U−1]`。
- 集合一律用**规范游程**：升序闭区间 `[s_i, e_i]`，满足 `s_1 ≥ 0`、`s_{i+1} ≥ e_i + 2`、`e_k ≤ U−1`；
  相邻或重叠的片段必须先合并，空集就是 0 个游程。
- `runs = k`、`count = Σ (e_i − s_i + 1)`、`l_i = e_i − s_i + 1 ≥ 1`；间隙 `g_1 = s_1`、
  `g_i = s_i − e_{i−1} − 1 ≥ 1`。
- 体积上界 `bound = 40 + 10 × runs`（40 字节头，加每个游程两个至多 5 字节的无符号 varint）：任何集合与
  运算结果都要 `bytes ≤ bound`，且 `bytes = 40 + 载荷字节数`，`crc32` 是载荷的 `zlib.crc32`。
- 耗时口径：单进程墙钟（`time.perf_counter`）、预热后 3 次取中位数，不含解释器启动与读文件；内存口径：
  `tracemalloc` 扣基线后的峰值。

## 三、数据结构与流水线

一条命令固定走四步：**解析**输入行（单点或闭区间）→ **归一**（排序并合并重叠与相邻，得到规范游程）→
**运算**（两个游程序列并行扫描）→ **编码**（写载荷与 40 字节头）或 **渲染**（结果记录、报告）。

不变量：游程互不相邻、按起点升序、长度 ≥ 1；`count`、`runs` 与片段内容在任何输出里都必须自洽。
不存在位图：全程只留游程，内存随 `runs` 线性增长——把集合摊成逐元素列表或整幅位图（2^32 位 = 512 MiB）
会在内存预算上当场超掉。

## 四、输入输出与文件格式

本节文件一律 UTF-8 无 BOM、`\n` 换行、末行有换行；数字十进制、不带正负号；记录行用 `|` 分隔 `键=值`。

### 4.1 集合文件 `samples/sets/*.txt`

`#` 开头的行与空行忽略；其余每行一个片段：`x`（单点）或 `a b`（闭区间，`a ≤ b`，半角空格分隔）。片段可
乱序、可重叠、可重复，解析时取并集。非整数、区间反向、越界、列数不符都是输入错误：退出码 2，stderr 一行
`error: …`，不写任何输出文件。

### 4.2 命令

```
python3 bitsetfold.py card   <集合文件>
python3 bitsetfold.py has    <集合文件> <元素>
python3 bitsetfold.py subset <A文件> <B文件>
python3 bitsetfold.py op     <and|or|sub> <A文件> <B文件>
python3 bitsetfold.py size   <集合文件>
python3 bitsetfold.py pack   <集合文件> <输出.bsf>
python3 bitsetfold.py unpack <输入.bsf>
python3 bitsetfold.py report <样例根目录> <输出.html>
```

### 4.3 命令行输出

- `card` → `CARD|n=<基数>`；`has` → `HAS|in=true|false`；`subset` → `SUBSET|sub=true|false`（`sub` 指 A ⊆ B）。
- `op`、`unpack` → 首行 `RESULT|op=<and|or|sub|unpack>|n=…|runs=…|bound=…`，其后按升序每行一个结果片段
  （`x` 或 `s e`）；空集时片段区只有一行 `EMPTY`。
- `size`、`pack` → `SIZE|n=…|runs=…|payload=…|bytes=…|crc32=…|bound=…`（`crc32` 8 位小写十六进制）；
  `pack` 另把 `.bsf` 写到给定路径，父目录不存在就建。
- `report` → 全部通过时 stdout 一行 `ok=<命令条数>`；有不符时每条打一行 `mismatch=<命令参数>`，退出码 1。
- 退出码：0 成功、1 有不符或内部错误、2 输入或用法错误；同一条命令两遍输出逐字节相同。

### 4.4 期望脚本 `samples/expected/<名>.txt`

`#` 开头是注释；`? ` 开头是本工具的参数（等价于 `python3 bitsetfold.py <参数>`，相对路径按仓库根解析）；
其余行是上一条命令的期望 stdout，连末尾换行逐字节比对。`report` 按这条规则执行并核对，现有期望脚本共
87 条命令。

### 4.5 `.bsf` 序列化（版本 1）

头 40 字节，从偏移 0 起依次是：魔数 `BSF1`(4)、版本 `1`(1)、编码 `1`（游程 varint）(1)、保留 0(2)、
`count`(u64)、`runs`(u64)、载荷字节数(u64)、载荷 `crc32`(u32)、保留 0(4)；除魔数外全部小端。

载荷按游程顺序写 `g_i`、`l_i` 两个**无符号 LEB128**（7 位一字节、最高位是续位、取最短编码）。解码
`s_1 = g_1`、`s_i = e_{i−1} + 1 + g_i`、`e_i = s_i + l_i − 1`；还原出的游程不满足规范形式就是坏文件。
自描述：只凭文件本身（魔数、版本、编码、`count`、`runs`、长度、`crc32`）即可校验并还原，不依赖文件名。

### 4.6 报告

`report <样例根目录> <输出.html>` 执行 `<样例根目录>/expected/*.txt` 里的每条 `? ` 命令并逐行比对，再写一份
单文件 HTML：数据与样式内联、不引外链、双击即开；按样例分节列出每条命令的通过情况与耗时，以及
`SIZE`/`RESULT` 行的 `n`、`runs`、`payload`、`bytes`、`crc32`、`bound` 与 `bytes ≤ bound` 的结论。

## 五、性能与验收口径

测试机 Windows + Python 3.13、单进程单线程；样例 5 组 10 份集合。

1. 逐条核对：`report samples var/report.html` 必须 `ok=87`，报告里没有不符项。
2. 体积：每个 `.bsf` 都 `bytes ≤ bound`；`05_nearfull_*` 只有 2 至 4 个游程，`.bsf` ≤ 80 字节。
3. 往返：`unpack(pack(S))` 与 `op` 的片段一致；同一集合 `pack` 两遍逐字节相同；坏文件（改版本、截断、改
   `count`、破坏载荷）退出码 2 且不出结果。
4. 单元素判断：`03_random_a`（3000 游程）与 `05_nearfull_a`（约 4.29×10^9 个元素、4 游程）上各连续 `has`
   10^5 次，平均 ≤ 5 µs/次；线性扫描会在前者上超。
5. 集合运算：`op and|or|sub` 单次 ≤ 100 ms（`03_random_*` 与 `05_nearfull_*`），结果游程数必须等于期望脚本
   给出的 `runs`（合并干净，不碎片化）。
6. 内存：`05_nearfull_*` 的任何命令，`tracemalloc` 峰值 ≤ 64 MiB。
7. 确定性：同一命令连跑两遍、再换 `PYTHONHASHSEED=0/1/2` 跑，输出逐字节相同；跑完 `samples/**` 不许有改动。

## 六、样例说明

`samples/sets/<名>_a.txt`、`<名>_b.txt` 与 `samples/expected/<名>.txt` 三份同名一一对应；每份期望脚本都覆盖
`card`、`has`、`subset`、`and`、`or`、`sub`、`size`，`01`、`05` 另含 `pack`/`unpack`。

| 名 | 场景与关键数字 |
| --- | --- |
| `01_sparse` | 极稀疏：A 600 个孤立点（12,699,431 到 4,277,440,148），B = A ∪ 60 个新点；`and` 600 游程、`or` 660、`sub` 为 `EMPTY` |
| `02_ranges` | 连续区间：A 两段共 1000000、B 三段共 1967296；`and` 650000、`or` 2317296、`sub` 350000（2/3/2 游程） |
| `03_random` | 大量随机点：A、B 各 3000 个孤立点，公共 30 个；`and` 30、`or` 5970、`sub` 2970 |
| `04_edges` | 两端密集中间空：A、B 各 20000（`0` 与 `U−1` 两侧各 10000），B 文件乱序且含相邻片段 |
| `05_nearfull` | 接近全集：A 是全集挖掉 3 个点（4 游程）、B 两段 4242450944；`and` 4242450941（5 游程）、`or` 即全集（4294967296、1 游程）、`sub` 52516352（1 游程） |

`samples/notes.md` 是现场记录，只作背景，不作为口径。
